# chakuseki-now-mac 📱💻

このプロジェクトは、SwiftUIとSwiftDataを使用して構築された「着席状況」を管理するためのアプリケーションです。

## 🚀 起動方法

誰でも簡単にアプリを起動できるように、以下の手順に従ってください。

### 1. 準備するもの

- **Mac**: macOSが動作しているコンピューター。
- **Xcode**: 最新バージョンのXcodeがインストールされていること。

### 2. プロジェクトを開く

このディレクトリにある以下のファイルをダブルクリックしてXcodeを起動します。

- `chakuseki-now-mac.xcodeproj`

### 3. デバイスの選択

Xcodeの画面上部中央にあるデバイス選択ボタンをクリックし、実行したい環境を選びます。

- **iPhoneで動かしたい場合**: `iPhone 15` などのシミュレータを選択。
- **Macで動かしたい場合**: `My Mac` を選択。

### 4. アプリを実行する

- Xcodeの左上にある **「▶ (Run)」ボタン** をクリックします。
- または、キーボードの **`Command + R`** を押します。

> [!TIP]
> 起動に時間がかかることがありますが、シミュレータが立ち上がるまでそのままお待ちください。

---

## 📁 フォルダ構成の解説

- **`chakuseki-now-mac/`**: アプリのメインソースコード。
  - `ContentView.swift`: 画面のデザイン。
  - `chakuseki_now_macApp.swift`: アプリの起動設定。
- **`chakuseki-now-mac.xcodeproj`**: このファイルを開いて開発を開始します。
